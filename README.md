# JUNTAUCR · SINPE Móvil

Proyecto universitario: simulación de SINPE Móvil para la entidad ficticia JUNTAUCR (MySQL + Node.js).

- **Aplicación:** [`app/`](app/) (instrucciones en [`app/README.md`](app/README.md))
- **Prototipo navegable:** [`prototipo/index.html`](prototipo/index.html) (abrir con `?modo=demo`)
- **Guía de pantallas:** [`Guia-de-pantallas-JUNTAUCR.pdf`](Guia-de-pantallas-JUNTAUCR.pdf)
- **Contexto completo y cómo seguir:** [`AGENTS.md`](AGENTS.md)

```bash
cd app && npm install && copy .env.example .env   # poner DB_PASSWORD
npm run instalar-bd && npm start                  # http://localhost:3100
```
